# Master’s Delight – The Master’s Journey
React + Vite + Tailwind CSS. Level 1 Master’s Quick Quiz · Level 2 Blend the Master’s Delight · Level 3 Hunt the Master.

    npm install
    npm run dev        # local (also on your LAN)
    npm run build      # production build in dist/ (deploy to Vercel/Netlify/any static host)

Edit game content in `src/data.js` (quiz questions, blend ingredients, hidden bottle positions).
Timers/scoring: `TIME` constants at the top of each file in `src/components/`.
Images live in `src/assets/`. Please drink responsibly – adults of legal drinking age only.
